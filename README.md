# Kyon (earlier version, retired)

This repository published an earlier version of Kyon. It is archived, and
nothing is offered for download here any more.

The current Kyon is at [kyon.sh](https://kyon.sh) and
[kyon-sh/kyon](https://github.com/kyon-sh/kyon):

```sh
brew install --cask kyon-sh/kyon/kyon
```
