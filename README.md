# Kyon (earlier version, retired)

This repository published an earlier version of Kyon. It is archived and gets
no more releases.

Each release here still carries its source archive, and will keep doing so.

The current Kyon is at [kyon.sh](https://kyon.sh) and
[kyon-sh/kyon](https://github.com/kyon-sh/kyon). To move to it with Homebrew:

```sh
brew update
brew upgrade --cask --greedy kyon
```

That replaces this version's Kyon.app. Its settings live under a different
bundle identifier and are left as they were.
